Privacy Policy

Element Collector Chrome Extension · Last updated: October 19, 2026

1. Who we are

Element Collector (“the Extension”, “we”, “us”) is a browser extension that helps you select elements on websites, collect their HTML and CSS, edit them in a visual editor, and export to HTML, React, or Figma.

Contact: LinkedIn · GitHub

2. Features

Current features include:

  • Picking elements on any website you visit
  • Collecting HTML, CSS, interactive states, and responsive styles
  • Previewing collected elements in a side panel
  • Editing designs in a visual canvas editor
  • Exporting to HTML, CSS, React, Figma-friendly formats, PNG, or project files

We may add, change, or remove features over time (for example cloud sync, accounts, collaboration, templates, analytics, or AI-assisted tools). When we do, this policy will be updated and the “Last updated” date will change.

3. Data we handle today

Today, Element Collector is designed to work primarily on your device. When you use the Extension, the following may be stored locally in your browser (Chrome extension storage):

  • HTML, CSS, and related data for elements you choose to collect
  • Thumbnails / screenshots of selected regions
  • Editor project data (frames, layout, zoom, and similar editor state)
  • Temporary UI state needed to run the side panel and editor

To collect accurate CSS, the Extension may fetch stylesheets from websites you visit (including cross-origin stylesheets) when you pick an element. Those requests are made to provide the feature you requested and are not used by us to build a personal profile.

We do not currently operate a backend that receives your collected page content for storage on our servers.

4. Data we may collect in the future

As we add features, we may collect and process additional data, which could include:

  • Account information (such as email or name) if you create an account
  • Usage and product analytics (for example feature usage, crash reports, performance)
  • Feedback you submit to us
  • Synced projects or collected elements if you opt into cloud backup or sharing
  • Technical data such as browser type, extension version, and approximate region

If we begin collecting data beyond local device storage, we will update this Privacy Policy and, where required, provide in-product notice or ask for consent. You can uninstall the Extension at any time to stop further local processing.

5. How we use data

We use data only to:

  • Provide and improve Element Collector features
  • Save your collections and editor projects
  • Export files you request
  • Diagnose issues, prevent abuse, and understand product usage (if analytics are added)
  • Communicate with you about support or updates if you contact us

We do not sell your personal information.

6. Sharing

We do not sell or rent your data. If future features rely on service providers (for example hosting, analytics, or authentication), those providers will process data only as needed to run the service, under appropriate agreements.

We may disclose information if required by law, or to protect users, the Extension, or others from fraud or security issues.

7. Retention

Local data remains in your browser until you delete collected items, clear extension storage, or uninstall the Extension. If we later store data on servers, we will keep it only as long as needed for the feature or as required by law, and describe retention in an updated version of this policy.

8. Your choices

  • You control what elements you collect
  • You can delete collected items from the Extension UI
  • You can clear site/extension data in Chrome settings
  • You can uninstall Element Collector at any time

9. Children’s privacy

Element Collector is not directed at children under 13 (or the minimum age in your country). We do not knowingly collect personal information from children.

10. Changes to this policy

We may update this Privacy Policy when features change or when we start collecting additional data. The latest version will always be published at this page URL. Continued use of the Extension after an update means you accept the revised policy.
